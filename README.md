## Projects

### [Multi-Tenant Cloud Hosting Platform](https://github.com/OmarHajjeh/erpnext-saas)

Production ERPNext SaaS on Oracle Cloud (Ampere A1 / ARM64). A Bash CLI provisions a full per-customer stack in one command, and Traefik issues SSL for every tenant subdomain through the Cloudflare DNS-01 API with no manual steps.

`Docker Compose` `Traefik` `Cloudflare` `Oracle Cloud` `Bash`

### [Self-Hosted Portfolio & CI/CD Pipeline](https://omarlab.me)

GitHub Actions builds, tests, and deploys every push to my server. Containerized behind a reverse proxy with automated SSL.

`GitHub Actions` `Docker` `Traefik`

### [Home Lab Infrastructure](https://github.com/OmarHajjeh/Home-Lab)

10+ Dockerized services managed with Docker Compose and Portainer. Nginx reverse proxy with SSL termination, remote access over Tailscale and Cloudflare Tunnels, Uptime Kuma for monitoring, AdGuard Home for DNS filtering. Where I test things before using them anywhere that matters.

`Docker` `Portainer` `Nginx` `Tailscale` `Uptime Kuma`

### [Proxy Comparative Analysis](https://github.com/OmarHajjeh/Proxy-Comparative-Analysis)

Benchmarked Nginx, HAProxy, and Caddy as load balancers across a stateless 3-tier architecture, with MySQL master-slave replication and Redis session caching.

`Nginx` `HAProxy` `Caddy` `MySQL` `Redis`
